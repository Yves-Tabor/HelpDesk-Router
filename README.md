# HelpDesk — React Router Challenge

A pre-built support ticket dashboard with **no routing**. Your job is to wire it up.

## Setup

```
npm install
npm run dev
```

## What's inside

- `src/data.js` — 6 support tickets with activity logs
- `src/components/` — 11 fully styled components
- `src/App.jsx` — imports everything, routes are up to you
- `src/App.css` — all styles are done, don't touch this

## The rules

- Don't modify the CSS
- Don't modify the data
- Don't use AI tools
- React Router docs are fair game: https://reactrouter.com
